# DSA Java

This repository is organized by topic so the root folder stays clean and the Java exercises are easier to browse.

## Structure

- `src/leetcode/` - LeetCode problem solutions
- `src/dsa/` - data structures and algorithm learning exercises
- `src/practice/` - quick-practice and scratch Java programs

## Notes

- The original project folders were regrouped into the `src/` tree to reduce clutter.
- Java class files and temporary I/O files are ignored to keep the repository focused on source coded.
